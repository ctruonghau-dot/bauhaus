# BAUHAUS AI · 使用说明

BAUHAUS AI 是一个在本机运行的服装短片导演。放进一张服装照片，它会：

1. 读懂这件衣服；
2. 写创意和文案，拆成五个镜头；
3. 画出每一镜的第一帧，并逐张对照原图检查；
4. 交给小云雀（Seedance 2.0 Mini）生成视频；
5. 剪辑、配字幕和配乐，得到一支约 24 秒的自然主义生活方式短片。

---

## 一、运行环境

| 项目 | 要求 |
| --- | --- |
| 系统 | macOS、Windows、Linux 均可 |
| Python | 3.8 或更新。只用标准库，不需要安装依赖 |
| 浏览器 | Chrome、Edge 或 Safari 的新版本 |
| 网络 | 能访问 OpenAI 与小云雀（xyq.jianying.com） |
| 账号 | OpenAI API Key 和小云雀 Access Key（只有工作模式需要） |

macOS 第一次运行 `python3` 时，如果系统提示安装“命令行开发者工具”，点安装即可。

---

## 二、快速开始

1. 启动本地服务：
   - **macOS**：双击 `启动 BAUHAUS AI.command`。如果系统提示“来自身份不明的开发者”，右键这个文件 → 打开 → 再点一次“打开”。如果双击没有反应，在终端运行 `chmod +x "启动 BAUHAUS AI.command"` 后再双击。
   - **任何系统**：在项目文件夹里运行 `python3 server.py`（Windows 上可能是 `python server.py`）。
2. 浏览器会自动打开 `http://127.0.0.1:7788`。
3. 先在**演示模式**里看一遍完整流程。这个模式不需要密钥，也不花钱。
4. 要做自己的片子：切到**工作模式**，点右上角 **「API 设置」** 填写密钥（见第三节）。
5. 把一张服装照片拖进页面中间的圆圈，点 **「确认」**。

启动时打开的终端窗口就是本地服务。关掉它即可停止。

---

## 三、API 设置

点主页右上角的 **「API 设置」**：

| 项目 | 说明 |
| --- | --- |
| OpenAI API Key | `sk-` 开头。用于看图、策划、写文案、画首帧、质检、剪辑决策 |
| 小云雀 Access Key | `ak-` 开头。用于生成视频 |
| GPT 模型 | 默认 `gpt-6.2-sol` |
| 视频模型 | 默认 `Seedance_2.0_mini_lite` |

- 填好后点 **「保存」**，再点 **「测试连接」**。两项都显示“可用”就可以开始了。测试不消耗积分。
- 已保存的密钥只显示末四位。留空表示保持原值不变。
- 按钮上的小圆点：绿色表示两项都已配置；橙色闪烁表示还缺一项。在工作模式下，如果没配齐就点确认，设置面板会自动弹出。
- 密钥只保存在本机项目文件夹里的 `keys.json`，只有你的系统账户能读，并且已被 `.gitignore` 排除，不会被提交到仓库。删除 `keys.json` 即可清除。

## 四、工作流程

页面会自上而下自动推进，并跟随当前步骤滚动。

| 步骤 | 做什么 | 结束后 |
| --- | --- | --- |
| 01 输入 | 在本地读取图片，提取主色 | 自动继续 |
| 02 理解 | GPT 看图，判断品类、面料、廓形、细节，并写下一段严格的外观描述（用来锁定还原度） | 自动继续 |
| 03 策划 | 片名、创意、场景、光线、配乐方向、五屏商品文案、人物造型 | **等你确认** |
| 04 分镜 | 五个镜头：环境 → 触摸 → 穿着中的日常 → 动态细节 → 人在环境里 | **等你确认** |
| 05 首帧 | GPT 画每一镜的第一帧，再逐张和商品原图比对；不像就打回重画，最多四轮 | **等你确认** |
| 06 生成 | 小云雀以首帧为起点，五个镜头同时生成，每镜 5 秒 | **等你确认** |
| 07 成片 | GPT 决定剪辑点、定稿字幕、挑配乐；浏览器实时合成、调色、混音并录制 | 首映 |

**确认方式**：右下角固定位置的「确认 进入下一步 →」按钮，或者按回车。在首帧之后、提交小云雀之前，确认提示会写明大约消耗多少积分。

**首帧质检**：每一镜的首帧都会核对以下几项是否和商品原图一致：

- 衣服本身：颜色、面料、毛向、衣长、廓形、领型、袖口、门襟、里布，并给出 0–10 的还原分；
- 其他穿帮：手指与肢体是否正常，有没有文字、水印、logo、衣架、吊牌，人物是否前后一致。

还原分低于 7、任何一项“明显不同”，或者出现明显穿帮，都会重画。四轮之后仍不通过，就采用还原分最高的那一张。卡片上会显示“还原 8/10”这样的分数。

**成片规格**：

| 项目 | 规格 |
| --- | --- |
| 镜头 | 5 个，每镜保留 3.6–4.6 秒 |
| 片尾卡 | 约 3.4 秒：品名与一句收束 |
| 总长 | 约 24 秒 |
| 画幅与分辨率 | 3:4 竖幅，960 × 1280 |
| 文件格式 | 优先 MP4，不支持时为 WebM |
| 字幕 | 五屏商品说明，每镜一屏：第一屏是品名，最后一屏是穿着感受 |
| 配乐 | 来自 Openverse 检索的 Jamendo CC 授权曲目，署名显示在首映页 |

成片会自动保存到 `作品/`，首映页也可以直接下载。

## 五、两种模式

左上角的「演示 / 工作」一键切换。

- **演示模式**：不调用任何接口，不花钱。无论放入什么图，都会回放标杆样片《冬日买面包》（皮草质感短款外套）的真实产出，包括理解、策划、分镜、首帧与质检记录、五段视频、剪辑、字幕和配乐。素材在 `demo/`。
- **工作模式**：真实调用 OpenAI 和小云雀，需要先完成 API 设置。

---

## 六、费用与耗时

- **小云雀**：每支片约 **100 积分**（5 镜 × 5 秒）。每镜约 2–5 分钟，五镜同时生成。
- **OpenAI**：
  - 文本：理解、策划、剪辑共 3 次；
  - 首帧生图：每镜 1–4 次，共 5–20 次；
  - 质检：与生图次数相同。
  - 生图是最慢的环节，每张约 1 分钟。
- **失败兜底**：某镜视频生成失败、且尚未扣费时，会自动重试一次。仍失败的，用首帧做缓慢推镜代替，保证成片完整。

## 七、常见问题

**端口被占用？**
先关掉已经打开的 BAUHAUS AI 窗口。或者换一个端口启动：`BAUHAUS_PORT=7799 python3 server.py`。

**提示“还没有配置 … 请点主页右上角「API 设置」”？**
按第三节填写密钥，然后点「测试连接」。

**测试连接显示“密钥无效”？**
检查密钥是否复制完整、前后有没有多余空格，以及账号里是否还有余额或积分。

**首帧一直被打回？**
复杂面料（长毛、强斑驳）比较难画。四轮之后会采用最接近原图的一张。商品原图越清晰、越完整，效果越好。

**视频下载失败？**
小云雀的视频 CDN 偶尔会拒绝连接。本地服务会自动改用系统的 curl 并重试，页面也会重新获取下载地址，一般能自行恢复。

**录制时要注意什么？**
最后一步是在浏览器里实时合成录制的（约 24 秒）。录制期间请让页面保持在前台，不要最小化或切换到别的标签页。

**商品图里有吊牌？**
提示词已经要求不要画出吊牌，但拍照前最好先把吊牌摘掉。

**我的数据会发到哪里？**
- 商品图片只发给 OpenAI（理解、生图、质检、剪辑）和小云雀（生成视频）。
- 配乐检索只向 Openverse 发送几个英文关键词。
- 本地服务只监听 127.0.0.1，并且只接受本页面发出的请求，其他网站无法借用它。
